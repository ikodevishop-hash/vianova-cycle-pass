# Vianova Cycle Pass — 管理マスター（Web）

ブラウザで動く管理画面です。APIサーバー（`../vianova_server`）に接続して、
顧客・自転車・レンタル・お知らせ・**4言語の利用規約**を管理します。

## 使い方

1. 先に APIサーバーを起動（`cd ../vianova_server && npm start`）。
2. `index.html` をブラウザで開く（ダブルクリック、または任意の静的サーバーで配信）。
3. ログイン画面で **サーバーURL**（既定 `http://localhost:4080`）と
   **パスワード**（初期値 `master123`）を入力。

> 静的サーバーで配信する例： `npx serve vianova_admin` など。
> `file://` で直接開いても動作します（サーバー側で CORS を許可済み）。

## 機能

- ダッシュボード（会員数・車種・レンタル中・月間売上）
- 顧客管理（一覧／詳細・本人確認画像・メール確認状況、お知らせ送信）
- 自転車登録（写真最大4枚・料金・スペック・車体番号・保険期限・在庫の登録／編集／削除）
- **利用規約変更（4表記）**: 日本語／English／中文／한국어をタブで切り替えて編集。
  「この表記を保存」または「4表記すべて保存」で即サーバーへ反映 →
  アプリのログイン後の利用規約は、利用者が選んだ言語の表記で表示されます。
- レンタル状況（一覧・CSV書き出し）

設定（サーバーURL）はブラウザの localStorage、ログイントークンは sessionStorage に保持します。
